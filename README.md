# Paswurdium

#### Generate bunches of passwords.
You can use the default version at https://braininabowl.github.io/Paswurdium/, but I highly recommend cloning this project and filling the word buckets with your own content.

## How to use

1. Open "index.html"
2. Click "Generate passwords"
3. Profit!

By default Paswurdium generates 10 long passwords for every click on the button, using a variety of structures (either random gobbledegook or easy to remember sentences).

## Recomendations

Out of the box, Paswurdium only knows a small amount of words to build passwords from. I highly recommend opening the various "Bucket" files in the "Buckets" folder and fill them with your own words to generate hard to guess and secure passwords.
